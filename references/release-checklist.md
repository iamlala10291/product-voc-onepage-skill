# Public release checklist

## Analysis

- Scope, source, date range, sample, and counting unit are visible.
- Facts, supported candidates, inferences, and unknowns are separated.
- Broad hits are not reported as actual inquiry.
- Visitor profile is not reported as buyer profile.
- Activity refunds and logistics events are not reported as product-experience refunds.
- Customer service is not blamed without isolating evidence.

## Content

- No unsupported safety, efficacy, ingestion, pregnancy, sensitivity, compatibility, or medical claim.
- No customer ID, nickname, phone, address, order number, conversation ID, raw quote, or screenshot containing personal data.
- No private activity rule, internal BI export, internal evidence report, or unpublished product material.
- No local path, intranet URL, cookie, token, password, API key, `.env`, or browser profile.
- The example is explicitly fictional.

## Visual

- Export PNG dimensions match the artifact's declared native canvas (the ANKNI mind-map example is 3840×14400).
- No overflow, failed images, footer overlap, or unreadably compressed text.
- Product-derived tokens are documented.
- Font fallbacks support Simplified Chinese.

## Repository

- Secret/privacy scan passes.
- `git status` contains only intended files.
- README explains scope, privacy, setup, and license.
- Repository visibility is public by explicit authorization.
- Remote default branch and latest commit are verified after push.
